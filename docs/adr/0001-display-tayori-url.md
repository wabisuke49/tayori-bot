# ADR 0001: FAQ 検索結果に Tayori URL を表示する

## Status

Accepted

## Context

FAQ 検索結果から、ユーザーは Tayori の記事へ移動して詳細な手順を確認する。

記事タイトルだけをリンクにすると、遷移先が Tayori であることや、次にリンクを押す操作が必要なことが伝わりにくい。

## Decision

検索結果では記事タイトルを通常のテキストとして表示し、その下に Tayori の URL をハイパーリンクとして表示する。

## Consequences

- Tayori へ移動することを URL から意識できる。
- ユーザーが次に押す場所を把握しやすい。
- URL が長く表示されるため、将来の UI 改善では表示方法を再検討する余地がある。
